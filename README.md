# 毕业设计：Agent 安全保护

围绕 Agent 自我复制约束、紧急强制终止与多 Agent 隔离，整理题目说明、会议记录、基础学习资料和教学示例，逐步开展软硬件协同安全架构研究。

## 当前学习目标

依据 11 月 6 日会议，本阶段先熟悉 RTL 编写、硬件开发工具和操作系统进程生命周期，并思考如何把高层安全目标转化成具体、可验证的技术目标。

会议记录中的工具名称存在转写差异，学习资料暂按后文明示的 **Chisel** 组织，仍待向导师核实。

## 配套示例

本机工作台的组件、版本、运行路径和任务菜单见 [当前开发环境说明](学习资料/当前开发环境说明.md)，也有 [PDF 版](学习资料/当前开发环境说明.pdf)。

按自己的系统选择入口：

- [macOS：Apple Silicon / Intel](学习资料/配套示例/macOS/README.md)
- [Windows：PowerShell 与 WSL 选择](学习资料/配套示例/Windows/README.md)
- [Ubuntu / WSL Ubuntu](学习资料/配套示例/Ubuntu-WSL/README.md)

三个系统共用源代码，各自提供安装说明与启动入口。Python 示例只依赖标准库，分别演示父子进程、管道通信、终止与回收，以及简单的策略模型。总体说明见 [代码入口](学习资料/配套示例/README.md)，实际测试范围见 [验证记录](学习资料/配套示例/示例说明与验证记录.md)。

RTL 示例包括选择器、计数器和停止门，配有测试平台；Chisel 示例包括固定依赖、生成入口、生成后的主模块及测试适配器。手写停止门与 Chisel 适配器使用相同模块名，请按说明分别编译。

语法综合示例为 `syntax_basics.sv` 与 `SyntaxBasics.scala`，展示同样的分支选择、位拼接、保留进位和计数器。VS Code 打开整个仓库后，在“终端 → 运行任务”选择“语法：”开头的任务；[使用入口](学习资料/配套示例/Windows/VSCode使用入口.md) 给出完整说明。

资料制作时，Python 示例已在 Windows 与 Ubuntu 运行，RTL 已进行 Icarus 功能仿真，Chisel 已生成 RTL 并通过定向测试。macOS 步骤依据官方文档补充，尚未在实体 Mac 实测；Linux 的 `/proc`、cgroup 等内容已单独标明。未进行 FPGA 实测。资料中的系统方案与指标属于教学候选。

临时文件、构建缓存及仿真产物由 `.gitignore` 排除。
