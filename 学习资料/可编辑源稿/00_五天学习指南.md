# 五天学习指南
## 从零开始，为 11.6 会议任务做准备

这套资料只围绕本周任务：熟悉 RTL 编写、会议中提到的硬件开发工具、操作系统进程生命周期，并思考如何把高层安全目标转成具体技术目标。默认你没有数字电路、Scala 或操作系统基础。

你将接触一条完整链路：电路能够保存状态 → 用 RTL 描述电路 → 用 Chisel 生成 RTL → 操作系统管理运行中的程序 → 为 Agent 的启动、通信与停止寻找控制点。

## 资料怎么分
| 分册 | 主要解决的问题 | 建议用时 |
| 01 数字电路与 RTL | 怎样读懂和编写最小硬件模块？ | 6 小时 |
| 02 Chisel 与工具链 | Chisel、Verilog、仿真器各做什么？ | 3 小时 |
| 03 操作系统进程 | 程序怎样创建、运行、通信和退出？ | 5 小时 |
| 04 技术目标转化 | 怎样把课题愿景写成可验证的问题？ | 3.5 小时 |

建议每天约 3.5 小时，五天合计约 17.5 小时。知识点标为“必学”的先完成；“选读”用于理解边界，不要求本周掌握。练习答案放在对应分册末尾，先作答再翻答案。

## 一个需要保留的疑问
会议记录混用了 Trisim、Trisol 和 Chisel。结合后文明示的 Chisel 与 Chipyard，本资料按 Chisel 组织工具学习；这是一项有依据的解释，仍应向导师核实原词。Chisel 是硬件构造语言，不能直接理解成仿真器。[C1]

> 五天的目标是建立基础、做出小例子、提出初步技术目标。资料中的示意架构、候选指标与实验表格都是教学内容。

资料编写日期：2026-11-07。研究背景依据本地题目图片与 11.6 会议记录；技术参考优先采用项目官方文档、Linux 手册和 Python 文档。

## 遇到不懂的词怎么办
第一遍只问“它是什么、在整个链路的哪里、输入输出是什么”。例如先把 MMU 理解成“受操作系统配置的地址翻译与访问权限硬件”，暂时跳过页表格式。第三次遇见同一词，再返回分册内的定义复习。

- 用自己的话复述一个概念，禁止只抄定义。

# 先认识你的实验环境
## 文件与命令，从最少的开始

所有 PDF 位于“学习资料”；可直接运行的代码在“配套示例”；可编辑正文在“可编辑源稿”。建议先用文件管理器找到文件，再打开终端。终端是接受文字命令的程序，当前目录决定相对文件名指向哪里。

Windows 中可在 PowerShell 进入示例目录：
```powershell
Set-Location -LiteralPath 'D:\Projects\毕设\学习资料\配套示例'
python --version
python process_demo.py
```
第一行切换目录；第二行检查 Python；第三行运行文件。若 `python` 无法识别，也可尝试 `py -3`。这些 Python 示例只使用标准库，不需要安装第三方包。

## 两条实验路径
| 路径 | 适合什么内容 | 本周如何使用 |
| Windows + Python | 父子进程、等待、管道、策略模型 | 必做的低门槛动手路径 |
| 已有 Ubuntu / WSL | RTL 仿真、Linux 命令、Chisel 工具链 | 有环境就做；暂时没有可先手算 |

WSL 是 Windows 内的 Linux 运行环境。Windows PowerShell 与 Ubuntu 终端的命令不能混着直接输入。在 WSL 中，D 盘路径通常写为 `/mnt/d/`。以下命令在 Ubuntu 终端执行：
```bash
cd '/mnt/d/Projects/毕设/学习资料/配套示例'
python3 process_demo.py
```

RTL 示例采用 SystemVerilog 的一小部分常用语法，文件后缀为 `.sv`；仿真时用 `iverilog -g2012`。Chisel 示例的依赖配置按官方单文件模板获取，具体步骤见 02。

## 安装卡住时的处理
先看报错属于“找不到命令”“找不到文件”还是“下载失败”。安装最多占用本次学习 30 分钟，之后先完成手算和阅读。每个例子都给了预期现象，后续可补做实验。资料制作时的实际测试范围另见“示例说明与验证记录”。
