# 五天学习指南
## 从零开始，为 11.6 会议任务做准备

这套资料只围绕本周任务：熟悉 RTL 编写、会议中提到的硬件开发工具、操作系统进程生命周期，并思考如何把高层安全目标转成具体技术目标。默认你没有数字电路、Scala 或操作系统基础。

你将接触一条完整链路：电路能够保存状态 → 用 RTL 描述电路 → 用 Chisel 生成 RTL → 操作系统管理运行中的程序 → 为 Agent 的启动、通信与停止寻找控制点。

## 资料怎么分
| 分册 | 主要解决的问题 | 建议用时 |
| 01 数字电路与 RTL | 怎样读懂和编写最小硬件模块？ | 6 小时 |
| 02 Chisel 与工具链 | Chisel、Verilog、仿真器各做什么？ | 3 小时 |
| 03 操作系统进程 | 程序怎样创建、运行、通信和退出？ | 5 小时 |
| 04 技术目标转化 | 怎样把课题愿景写成可验证的问题？ | 3.5 小时 |

另附 05《按操作系统运行代码》，按自己的系统查阅即可。它是五天内动手环节的操作手册，不额外增加一天。

建议每天约 3.5 小时，五天合计约 17.5 小时。知识点标为“必学”的先完成；“选读”用于理解边界，不要求本周掌握。练习答案放在对应分册末尾，先作答再翻答案。

## 一个需要保留的疑问
会议记录混用了 Trisim、Trisol 和 Chisel。结合后文明示的 Chisel 与 Chipyard，本资料按 Chisel 组织工具学习；这是一项有依据的解释，仍应向导师核实原词。Chisel 是硬件构造语言，不能直接理解成仿真器。[C1]

> 五天的目标是建立基础、做出小例子、提出初步技术目标。资料中的示意架构、候选指标与实验表格都是教学内容。

资料编写日期：2026-11-07。研究背景依据本地题目图片与 11.6 会议记录；技术参考优先采用项目官方文档、Linux 手册和 Python 文档。

## 遇到不懂的词怎么办
第一遍只问“它是什么、在整个链路的哪里、输入输出是什么”。例如先把 MMU 理解成“受操作系统配置的地址翻译与访问权限硬件”，暂时跳过页表格式。第三次遇见同一词，再返回分册内的定义复习。

## 每天都做这三个动作
- 用自己的话复述一个概念，禁止只抄定义。
- 对一个示例预测输出，再实际运行或手工核对。
- 写下一个与课题有关的问题，例如“停止主进程后，子进程一定停止吗？”

> 如果当天只有 2 小时，优先读概念、完成逐拍表和自测；把安装和扩展阅读安排到后面。五天覆盖基础需要持续投入，快慢以自测结果为准。

# 先认识你的实验环境
## 文件与命令，从最少的开始

所有 PDF 位于“学习资料”，共用源代码位于“配套示例”。该目录另设 Windows、macOS、Ubuntu-WSL 三个入口，各有独立说明。先读 05 中自己的系统部分，再进入示例目录。

## 三个系统，三条入口
| 系统 | 在哪里输入命令 | 先运行什么 |
| Windows | PowerShell | py -3 run_examples.py python |
| macOS | 终端 Terminal | bash macOS/run_examples.sh python |
| Ubuntu / WSL | Ubuntu 终端 | bash Ubuntu-WSL/run_examples.sh python |

终端接收文字命令，当前目录决定相对文件名指向哪里。必须先进入“配套示例”，才能直接使用上表中的相对路径。

Windows 的作者路径示例：
```powershell
Set-Location -LiteralPath 'D:\Projects\毕设\学习资料\配套示例'
py -3 run_examples.py python
```
macOS 若把仓库放在下载目录：
```bash
cd "$HOME/Downloads/Graduation-Project/学习资料/配套示例"
bash macOS/run_examples.sh python
```
路径按自己的位置修改，也可输入 `cd ` 后把文件夹拖进 Mac 终端。WSL 中 D 盘通常写为 `/mnt/d/`；它是 Windows 的 Linux 环境，不能把 apt 命令直接放进 PowerShell。

三套入口共用教学源代码。将末尾的 python 改成 rtl 或 chisel，可分别运行仿真或生成 RTL；请先按 05 安装对应工具。Python 例子只用标准库。

## 哪些内容属于 Linux
进程创建、等待、通信的基础可在 Mac 学习；`/proc`、cgroup 与 Linux namespace 等专项机制需要 Linux 环境，不能在 macOS 原生终端原样执行。

## 安装卡住时的处理
先分清“找不到命令”“目录不对”与“下载失败”。安装最多占用本次学习 30 分钟，之后先做手算。macOS 步骤已核对官方说明，当前制作环境未在实体 Mac 实测；详细记录见配套说明。

# 五天结束时，怎样判断学到了
## 最低完成清单

- 能把 `1010` 换算成十进制，并解释 4 位无符号计数器为何会从 15 回到 0。
- 能区分组合电路与时序电路，指出计数器里的状态、时钟和复位。
- 能解释 RTL、Chisel、仿真器、FPGA 的关系，画出工具链。
- 能画出进程创建、就绪、运行、阻塞、退出、回收的关系。
- 能说明 `fork`、`exec`、`wait` 的区别，理解这些是 Linux / Unix 语境。
- 能说明主进程退出与整个 Agent 停止之间有哪些待核实的环节。
- 能给三个课题目标各写出保护对象、假设、控制点、指标和一项实验。

## 三分钟组会汇报框架
第 1 分钟：解释一个 Agent 可能由控制程序、推理服务、工具进程、文件与网络依赖组成，说明你暂定的管理边界。

第 2 分钟：展示小模块的逐拍行为，以及进程从创建到回收的图。用一个例子解释“控制一个状态位”与“让系统中的行为停止”之间还差哪些接口。

第 3 分钟：提出三条候选技术目标，说明每条怎么测、依赖什么信任假设，并列出需导师明确的两三个问题。
