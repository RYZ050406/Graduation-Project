# 五天基础学习资料

面向零基础读者，围绕 11.6 会议提出的 RTL、Chisel（会议转写名称待核实）、操作系统进程生命周期及技术目标转化编写。

PDF 分册与合订本位于上一级目录，代码位于 `../配套示例/`。

正文源稿为本目录中的 Markdown 文件。`build_pdfs.py` 将源稿排版为 PDF，`verify_materials.py` 检查 PDF 与示例。

学习者的分系统运行入口位于 `../配套示例/`，另有 05 操作手册。PDF 制作脚本是维护资料的作者工具，当前使用 Windows 字体路径；阅读 PDF 和运行教学示例不需要执行排版脚本。

资料中的研究方案、数值指标和实验数据示例均是教学用候选内容，不代表已实现的毕设结果。
