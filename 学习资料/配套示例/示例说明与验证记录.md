# 示例说明与验证记录

制作与验证日期：2026-11-07。实验均为有限的本地教学例子。不要一次编译目录中所有 `.sv` 文件：手写安全门与 Chisel 适配器使用相同的模块名，需要按下面两条路径分别编译。

## 1. Python：Windows 与 Ubuntu 均已运行通过

在本目录运行，Windows 用 `python`，Ubuntu 可用 `python3`：

```text
python process_demo.py
python pipe_demo.py
python terminate_demo.py
python policy_model.py
```

- `process_demo.py`：创建一个子进程，打印父子编号，正常退出并等待，退出码 0。
- `pipe_demo.py`：父进程通过管道收集 `hello from child`。
- `terminate_demo.py`：只停止该脚本创建的一个子进程，并完成等待回收；实际验证中 Windows 退出码为 1，Ubuntu 为 -15，这种差异符合平台终止机制不同。
- `policy_model.py`：8 条断言通过，打印 `PASS policy_model: 8 checks`。

策略模型不创建真实任务，不构成沙箱或真实的安全强制机制。

## 2. 手写 RTL：Icarus Verilog 12.0，Ubuntu / WSL 已仿真通过

```bash
iverilog -g2012 -s mux2_tb -o mux2.vvp mux2.sv mux2_tb.sv
vvp mux2.vvp
iverilog -g2012 -s counter4_tb -o counter4.vvp counter4.sv counter4_tb.sv
vvp counter4.vvp
iverilog -g2012 -s safety_gate_tb -o gate.vvp safety_gate.sv safety_gate_tb.sv
vvp gate.vvp
```

- mux2：全部 8 种输入组合通过。
- counter4：复位优先、使能递增、禁用保持、15 到 0 的回绕通过，生成 VCD 波形。
- safety_gate：未授权拒绝、授权放行、停止位保持、复位优先、复位与停止同时出现等定向情形通过。

## 3. Chisel：已完成真实生成与生成结果仿真

教学固定版本：Scala CLI 1.9.1、Scala 2.13.16、Chisel 与编译器插件 7.2.0、Java 21；生成后端 CIRCT firtool 1.133.0。此组合用于复现，不表示最新版本。

```bash
scala-cli run chisel_project.scala SafetyGate.scala --main-class EmitSafetyGate
```

制作时以同一版本 Scala CLI 的本地 JAR 启动器运行上述项目，并使用 `--server=false`。依赖通过 Maven Central 下载；Chisel 自动取得配套生成后端。源码使用 `-disable-all-randomization` 关闭后端随机初始化附加代码；仍然需要正常驱动 reset。

生成器可能一次打印多个文件内容，使用分隔标记区分。`SafetyGate.generated.sv` 是从本次真实输出中提取的主模块，文件开头保留后端生成标识。其他验证层附加文件不是本例主模块仿真所必需。

`chisel_gate_adapter.sv` 把生成模块的端口名对接到手写安全门的接口，复用同一测试平台：

```bash
iverilog -g2012 -s safety_gate_tb -o chisel_gate.vvp SafetyGate.generated.sv chisel_gate_adapter.sv safety_gate_tb.sv
vvp chisel_gate.vvp
```

实际结果：`PASS safety_gate: policy/latch/reset priority`。这验证了所列定向输入序列，未执行形式等价证明。
