# 五天基础学习资料

先了解这台电脑怎样运行代码，可看 [当前开发环境说明](当前开发环境说明.md) 或 [PDF](当前开发环境说明.pdf)。它记录 Windows、WSL、VS Code 与仿真工具的分工，并列出已配置的任务。

先打开 `00_五天学习指南.pdf`，按每天约 3.5 小时安排学习。最新版为 `五天基础学习资料_合订本_含语法补充.pdf`，共 71 页；原 57 页合订本保留，优先看最新版。

1. 第 1—2 天：`01_数字电路与RTL.pdf`。从二进制和逻辑门读起，再学寄存器、计数器、状态机与仿真。
2. 第 3 天：`02_Chisel与工具链.pdf`。分清工具用途，阅读与运行 Chisel 小模块。
3. 第 4 天：`03_操作系统进程生命周期.pdf`。学习创建、调度、内存、通信、终止与回收，运行三个 Python 小实验。
4. 第 5 天：`04_从高层目标到技术目标.pdf`。用前面知识写一页可讨论、可验证的技术目标草案。

新增：01 分册第 14-20 页是 Verilog 语法 V1-V7；02 分册第 9-15 页是 Chisel 语法 C1-C7，含两种语言对照、示例、练习答案。V1-V3、C1-C3 先读，参数、数组、循环等按需查阅，五天安排无需全部背诵。

动手时按 `05_按操作系统运行代码.pdf` 选择自己的系统。配套代码位于 `配套示例`，内设 [macOS](配套示例/macOS/README.md)、[Windows](配套示例/Windows/README.md)、[Ubuntu-WSL](配套示例/Ubuntu-WSL/README.md) 独立入口；源代码共用。可编辑正文和排版脚本在 `可编辑源稿`。

会议工具名可能存在转写错误，本套暂按 Chisel 编写，并在资料中说明了核实依据与不确定性。

实际检查：Python 已在 Windows 与 Ubuntu 运行；RTL 和 Chisel 已在 Ubuntu / WSL 验证。macOS 步骤依据官方文档核对，尚未在实体 Mac 实测。资料中的系统架构和技术指标属于教学候选。
